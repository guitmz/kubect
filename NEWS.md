# News

## 0.1.0

Initial public release.

- Text focused Kubernetes sessions, reports, logs, incident tools, and resource
  workflows built around `kubectl`.
- Explicit confirmation for actions that change cluster state or open a
  connection.
- Asynchronous read only reports with cancellation, timeouts, and scoped cache
  behavior.
- RBAC aware namespace discovery that falls back to manual namespace entry.
- Tramp aware kubectl command resolution for remote buffers.
